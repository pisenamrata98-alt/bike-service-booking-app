# 📅 Bike Service Booking Application

A full-stack web application designed for users to view available services, schedule appointments, and manage booking requests online.

---

## 🌟 Key Features

* **Service Catalog:** View available services, descriptions, and pricing.
* **Appointment Scheduling:** Select dates and times for service bookings.
* **User Accounts:** Sign up and log in to manage active and past bookings.
* **Payment Gateway:** Online payment processing via BillDesk.
* **Admin Panel:** Manage incoming service requests, update booking statuses, and view user records.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript
* **Backend:** PHP
* **Database:** MySQL
* **Payment Gateway:** BillDesk API
* **Hosting / Server:** Apache / InfinityFree / Localhost (XAMPP / WAMP)
